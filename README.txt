تراث اللاذقية — نموذج موقع أولي

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html بمتصفح Chrome أو Edge أو Firefox.
3) يلزم اتصال بالإنترنت لتحميل الخطوط والخريطة وبعض الصور من مصادرها.

المحتويات:
- صفحة رئيسية عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- أرشيف بصري بروابط وصور تاريخية مرجعية.
- بطاقات معالم قابلة للتصفية.
- خريطة Leaflet / OpenStreetMap بنقطة توضيحية.
- واجهة رفع صورة ومعاينة وتحليل تجريبي (ليست متصلة فعلياً بنموذج AI).

مهم:
هذا نموذج Front-end جامعي وليس منصة إنتاجية. لا توجد قاعدة بيانات أو تسجيل دخول أو رفع ملفات إلى خادم. بعض المواقع والإحداثيات والبيانات الأولية تحتاج مراجعة ميدانية ومصادر متخصصة. تحقق من ترخيص كل صورة وشروط إعادة استخدامها. الصورة التاريخية المؤرخة 1810 من Wellcome Collection وموسومة Public Domain Mark؛ وصورة 1866 من Wikimedia Commons موسومة Public Domain.
